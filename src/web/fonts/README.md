# Review typography

The review interface uses the unmodified regular and bold OpenType fonts from
TeX Gyre Pagella X, distributed with [newpx](https://ctan.org/pkg/newpx), version
1.541. This is the Palatino-style family used by the reference thesis.

The fonts are bundled locally, with no external font requests. Vite emits them
as versioned assets for the production review page.

The font files retain their upstream names. See [GUST-FONT-LICENSE.txt](GUST-FONT-LICENSE.txt),
[LPPL.txt](LPPL.txt), [MANIFEST-newpx.txt](MANIFEST-newpx.txt), and
[README-newpx.txt](README-newpx.txt) for the upstream license, manifest, and attribution.
